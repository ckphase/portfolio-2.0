## 🎨 Design System

### Colors (Premium Restraint)
| Color | Usage | Value |
|-------|-------|-------|
| **Deep Black** | Background | #050505 |
| **White** | Text | #FFFFFF |
| **Electric Cyan** | Accents | rgba(125,211,252,1) |
| **Gray** | Secondary Text | rgba(255,255,255,0.6) |

**NOT Used**: Purple, Green, Orange, Pink, Rainbows

### Typography Scale
| Size | Weight | Use |
|------|--------|-----|
| 5-6rem | Light | Hero title |
| 3.5-4.5rem | Light | Section title |
| 2.5-3.5rem | Light | Subsection |
| 1rem | Light/Normal | Body text |
| 0.75rem | Medium | Labels |

### Motion
- **Primary Easing**: `[0.22, 1, 0.36, 1]` cubic bezier
- **Spring Physics**: stiffness 50, damping 30
- **Scroll Duration**: 1.2s (Lenis)
- **Hover Animation**: -4px lift, border glow
